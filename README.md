Este repositorio documenta mi solución a los desafíos del *Advent of Code*, abordados no solo como retos algorítmicos, sino como un ejercicio de arquitectura de software profesional. Este portafolio demuestra la aplicación de **fundamentos, principios y patrones de diseño** para construir sistemas robustos.

## Metodología de Diseño

Siguiendo la teoría, la arquitectura se divide en tres niveles fundamentales:

### 1. Fundamentos de Diseño 
Son las cualidades inherentes y deseables en el software:
* **Alta Cohesión:** Módulos enfocados en una única tarea.
* **Bajo Acoplamiento:** Módulos con pocas interdependencias.
* **Abstracción:** Ocultar detalles complejos tras interfaces simples.

### 2. Principios de Diseño 
Normas que guían la aplicación de los fundamentos:
* **SRP (Responsabilidad Única):** Cada módulo tiene una sola razón para cambiar
* **OCP (Abierto/Cerrado):** Abierto para extensión, cerrado para modificación.
* **DIP (Inversión de Dependencias):** Depender de abstracciones, no de detalles.
* **DRY:** Evitar repetición de conocimiento.
* **Ley de Demeter:** Conocimiento limitado entre unidades.

### 3. Patrones de Diseño
Soluciones típicas a problemas recurrentes:
* **Patrón Factory Method:** Encapsula la creación de objetos.
* **Patrón Iterator:** Separa la lógica de iteración de la estructura de datos.
* **Patrón Command:** Encapsula solicitudes como objetos para soportar transacciones.
